# Platform Project Starter

This repository provides a clean starter structure for a platform project.

## Structure

```
learn-github/
├── frontend/
│   └── .gitkeep
├── backend/
│   └── .gitkeep
└── README.md
```

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/potatoooo01/learn-github.git
   ```
2. Enter the project directory:
   ```bash
   cd learn-github
   ```
3. Start building inside:
   - `frontend/` for client-side code
   - `backend/` for server-side code

No dependencies are included by default.
